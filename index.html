        About this dashboard

        A static, dependency-free dashboard published by GitHub Pages. Quotes are streamed live from Yahoo Finance chart data via a CORS proxy, with CoinGecko and the Frankfurter exchange-rate API as independent fallbacks for crypto and FX. Charts are rendered by uPlot.

        Data sources

        • Yahoo Finance — equities, indices, FX, crypto chart data
        • CoinGecko — crypto spot prices (fallback)
        • Frankfurter / European Central Bank — FX reference rates (fallback)
        • r.jina.ai — CORS proxy for the Yahoo endpoints

        Good to know

        • Quotes may be delayed by the upstream provider.
        • When live feeds fail, the last committed snapshot is shown and clearly marked stale.
        • Market hours follow each exchange's local timezone.
